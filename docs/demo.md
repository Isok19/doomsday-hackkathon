# Демонстрация CQA — 5 минут

Команда: **zenoxxk**. Показывайте рабочую систему и настоящие сохранённые результаты.
Технические фикстуры тестов не являются результатами модели и для сдачи не подходят.

1. **0:00–1:00. Диалоги.** Открыть `/`, показать 60 чатов и 5 звонков DEV, языковые фильтры.
   Переключить набор на FBroker, показать 10 контрольных чатов. Открыть карточку с ролями и нумерацией.
2. **1:00–3:00. Оценка.** На реально обработанном диалоге показать восемь критериев, объяснения,
   переход к реплике, N/A и перераспределение веса, итог и отдельный флаг грубой ошибки.
   Если реального результата нет, честно показать причину, не подставлять тестовые оценки.
3. **3:00–4:00. Апелляция.** Оспорить критерий с комментарием. Открыть рассмотрение, подтвердить
   или изменить оценку с причиной и доказательством. Сравнить исходный и финальный итог.
4. **4:00–5:00. Изменение правил.** В редакторе сохранить новую версию правила и показать её в выборе
   чек-листа. При настроенном API оценить диалог по новой версии; старая оценка сохраняет старую версию.

Перед показом проверьте, что сервер запущен, модель доступна, а результаты DEV/FBroker уже выгружены.
Для официальных файлов сдачи используйте исходный чек-лист v1; экспериментальные изменения показывайте
отдельно. Докажите публикацию открытием двух results.json в GitHub после push.
