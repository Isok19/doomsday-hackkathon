# OpenAI API: баланс, лимиты и ошибки

`200 OK` в терминале означает успешную работу маршрута. `502` на запросе оценки означает,
что backend не получил пригодный ответ внешнего оценщика. Это не означает, что SQLite или весь сервер сломаны.
Начиная с обновления диагностики, ответ провайдера 429 передаётся клиенту как 429 с понятной причиной.

| Код | Причина | Действие владельца API-аккаунта |
| --- | --- | --- |
| `credit_balance_exhausted` | Закончились предоплаченные средства | Проверить Billing нужной организации и при необходимости пополнить баланс |
| `insufficient_quota` | Недостаточно квоты; общий код | Проверить баланс и бюджеты организации и проекта, которому принадлежит ключ |
| `project_spend_limit_exceeded` | Достигнут предел расходов проекта | Проверить бюджет/лимит именно проекта ключа |
| `organization_spend_limit_exceeded` | Достигнут предел расходов организации | Проверить лимит расходов организации |
| `organization_usage_limit_exceeded` | Достигнут установленный провайдером лимит | Запросить увеличение лимита; изменение локального кода не помогает |
| `rate_limit_exceeded` / `slow_down` | Слишком много запросов/токенов | Подождать минимум Retry-After, запускать пакет с `--workers 1` |
| 401 | Ключ отклонён | Проверить действующий ключ соответствующего проекта; не публиковать его |
| 403 / 404 | Нет доступа к выбранной модели | Проверить доступ модели для API-проекта |

1. Откройте https://platform.openai.com/settings/organization/billing/overview .
2. Убедитесь, что выбрана организация, к которой относится используемый API-ключ.
3. Проверьте доступные средства; изменение лимита само по себе не пополняет баланс.
4. Проверьте раздел Limits организации и лимит расходов проекта ключа.
5. После изменения выполните один проверочный запрос. Не запускайте весь набор повторно, пока он не успешен.

Платёж и изменение бюджета выполняет владелец аккаунта самостоятельно. Ключ не вставляют в чат или Git.
Если вы сменили ключ, остановите сервер Ctrl+C и снова запустите `python -m participant_3.serve`.
Скрытый ввод не отображает символы; после вставки нажмите Enter.
При обычных изменениях исходников сервер автоматически перезагружается с ключом в памяти родительского процесса.

Справка: [коды ошибок](https://developers.openai.com/api/docs/guides/error-codes),
[лимиты запросов](https://developers.openai.com/api/docs/guides/rate-limits).
Коды квоты/расходов нельзя исправить повторением запросов; сначала исправьте соответствующую настройку.
